# WebSockets_EmiliaFabara
## ¿Qué es un Web Socket?
Un web socket es un tipo de servidor que presta servio de intercambio de datos entre diferentes dispositivos e interfases.
## ¿Qué es Async y Await?
Async tiene la funcion de ser asincrona y await espera a que se complete una tarea asincrona.
## ¿Diferencia entre Array y Biblioteca?
Uno tiene datos vinculado con indice aquel que empieza en 0-1-2-3-4-5... y el otro tiene una clave.
